# Student Management System — GitHub Assignment 03

A collaborative Python project demonstrating Git branching, Pull Requests, code reviews, and merging workflows across multiple team members.

## Project Modules & Team Contributions

| Module | File Name | Contributor | Branch | Description |
| :--- | :--- | :--- | :--- | :--- |
| **Module 1** | `student_registration.py` | Fatima Bukhari (`@fatimax-coder`) | `member1-registration` | Registers new students with ID and name validation. |
| **Module 2** | `grade_calculator.py` | Member 2 Name (`@member2-username`) | `member2-grades` | Calculates student average scores and assigns letter grades. |
| **Module 3** | `attendance_tracker.py` | Member 3 Name (`@member3-username`) | `member3-attendance` | Tracks attendance percentage and checks exam eligibility (≥ 75%). |

## How to Run
Clone the repository and run any module using Python 3:

```bash
git clone [https://github.com/fatimax-coder/Github_Assignment03.git](https://github.com/fatimax-coder/Github_Assignment03.git)
cd Github_Assignment03
python student_registration.py
python grade_calculator.py
python attendance_tracker.py
